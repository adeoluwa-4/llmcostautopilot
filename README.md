# LLM Cost Autopilot

## What it does

LLM Cost Autopilot helps an AI app choose a model that fits the task, budget, and quality goal. It can start with a cheaper model and move to a stronger one when needed.

## What I built

I built the model routing rules, cost checks, quality checks, API, tests, browser console, and a local RAG search that finds useful text before sending a request to a model.
